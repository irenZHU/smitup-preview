# СМИТАП — дизайн-концепция

Интерактивный прототип двух экранов онлайн-школы: лента преподавателей и знакомство с Элей Смит.

## Локальный запуск

```sh
python3 -m http.server 4173
```

Открыть http://localhost:4173. Сборка и установка зависимостей не требуются.

HTML, CSS и JavaScript; видео преподавателя воспроизводится при наведении. В проекте учтена настройка уменьшения движения.
